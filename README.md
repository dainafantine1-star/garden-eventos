# Garden Eventos
Site responsivo do Garden Eventos, Teixeira de Freitas, Bahia. HTML, CSS e JavaScript, sem dependências de execução.

## Executar
`npm run build` gera a pasta `dist`. Publique como site estático.

## Vercel
Importe este repositório. O `vercel.json` configura o build e a pasta de saída.

## Conteúdo
Fotos e logo obtidos das publicações públicas de @gardeneventostx, incluindo colaborações com Hadnael Lirio, Jackeline Decorações, Dreams Decor e Valderi Fotografia. Mantidos localmente para não depender de URLs temporárias do Instagram.
WhatsApp e localização conferidos no Linktree oficial: https://linktr.ee/gardeneventos.
O logotipo disponível no perfil tem resolução reduzida; substituir `assets/0.jpg` pelo arquivo original quando fornecido.
Não há confirmação automática de reserva: o formulário abre o WhatsApp com as informações preenchidas. Não armazena dados no servidor.
